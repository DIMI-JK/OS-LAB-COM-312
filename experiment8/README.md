## Experiment 08

**Date:** 22/10/26  

**Aim:** Observe and understand the process map of the previous two programs using `pmap` command (or `vmmap` on macOS).

### Theory

* **`pgrep -a <pid>`** : to search for process by name or pattern & display their process IDs (PID).
* **`pmap -x <pid>`** : displays detailed memory usage of a process identified by its PID.
