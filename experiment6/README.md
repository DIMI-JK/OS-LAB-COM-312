# Experiment 06

**Date:** 29/09/26  
**EXP. No.:** 06  

## Aim
Write a C program that takes, as a command line argument, the no. of megabytes of memory it will use and during execution it should consume that much memory. Observe memory usage during program execution using `free` command.

---

## Theory

* **`free`** : displays the system's total, used, free and available memory, along with swap memory usage.
* **`free -h`** : displays memory usage in human-readable units such as KB, MB and GB.
